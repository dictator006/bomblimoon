# Bomb Lemon Experience

Create a modern, premium, fast, SEO-optimized Persian (RTL) website for a fast food brand called بمب لیمون.

The website should have a clean, modern, minimal design with excellent user experience. It must feel like a premium international fast-food brand while remaining simple and easy to use.

The website must be fully responsive for Mobile, Tablet and Desktop, with a mobile-first design approach.

Brand

Fast Food Name: بمب لیمون

Language: Persian (RTL)

Design Style:

 Modern

 Premium

 Minimal

 Clean

 Fast

 Professional

Home Page

Create an attractive landing page including:

 Hero banner with high-quality food image

 Fast Food logo

 Short biography/introduction

 "مشاهده منو" button

 Sticky navigation

 Smooth scrolling

 Modern animations

 Light Mode / Dark Mode switch

Digital Menu

Create a beautiful digital menu.

Each product should contain:

 Product Image

 Product Name

 Short Description

 Price

 Availability Status (Available / Unavailable)

Each product should have an Order button that redirects users directly to the Fast Food SnappFood page.

Menu Categories

Unlimited categories.

Allow the admin to add labels to products.

Supported labels:

⭐ فروش ویژه

🆕 جدید

The labels should appear as beautiful badges on the product cards.
